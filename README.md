# Light Brightness Check

Create a beginner-friendly AI mini project called "Broken Streetlight Detection System".

The project should be simple, clean, and easy to understand for an engineering student with basic Python knowledge.

Project Description:

The system should allow the user to upload a nighttime streetlight image and predict whether the streetlight is Working or Broken using a pre-trained image classification model.

Requirements:

1. Create a modern and responsive web interface.

2. Home Page

- Project title

- Short project description

- Attractive design

- Button to start detection

3. Upload Page

- Upload JPG, JPEG or PNG image.

- Display uploaded image.

- Detect button.

4. Prediction Page

Display:

- Uploaded image

- Prediction (Working Streetlight / Broken Streetlight)

- Confidence percentage

- Green color for Working

- Red color for Broken

5. About Page

Include:

- Problem Statement

- Objectives

- Advantages

- Future Scope

- Technologies Used

6. Technologies

- Python

- Streamlit

- TensorFlow/Keras

- OpenCV

- MobileNetV2 (Pre-trained Model)

7. Keep the code simple and well commented so a beginner can understand every file.

8. Organize the project into folders such as:

- app.py

- model/

- dataset/

- utils/

- assets/

- requirements.txt

- README.md

9. The application should allow the user to easily replace the dataset with two folders:

- Working

- Broken

10. Show a loading animation while prediction is running.

11. Display a success message after prediction.

12. Include proper error handling if no image is uploaded.

13. Use a professional blue and white color theme.

14. Add icons and a clean sidebar navigation.

15. Create a README file explaining:

- Project Overview

- Installation Steps

- Required Libraries

- How to Run

- Folder Structure

16. Generate a simple project report containing:

- Abstract

- Introduction

- Problem Statement

- Objectives

- Methodology

- Technologies Used

- Expected Output

- Conclusion

- Future Scope

17. Make the project look professional but keep the implementation simple and beginner-friendly.

Do not create unnecessary advanced features like live CCTV processing, GPS tracking, cloud deployment, login system, databases, APIs, or complex dashboards.

The final project should be easy to run, easy to explain in a college viva, and suitable as a beginner AI mini project.
